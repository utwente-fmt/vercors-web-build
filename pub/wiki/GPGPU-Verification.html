VerCors Tutorial

Try VerCors Online

This section explains how to verify GPGPU programs in VerCors. The tool supports both OpenCL and CUDA languages. The synchronization feature (i.e., barrier) in these languages is also supported by VerCors. To demonstrate GPGPU verification, we show two examples in both OpenCl and CUDA, one without barrier and the other one with barrier.

OpenCL/CUDA without Barrier

This simple method shows an OpenCL program that adds two arrays and stores the result in another array:

Warning

The following example verifies only on the latest VerCors development version, not on the version currently used by the online verifier.

#include <opencl.h>
/*@
 context get_work_dim() == 1;
 context get_local_size(0) == 32 && get_num_groups(0) > 0;
 context a != NULL && \pointer_length(a)> get_global_size(0);
 context b != NULL && \pointer_length(b)> get_global_size(0);
 context c != NULL && \pointer_length(c)> get_global_size(0);

 context Perm({:a[\gtid]:}, read);
 context Perm({:b[\gtid]:}, read);
 context Perm({:c[\gtid]:}, write);
 ensures {:c[\gtid]:} == a[\gtid] + b[\gtid]; @*/
__kernel void openCLAdd(global int a[], global int b[], global int c[]) {
   int tid = get_global_id(0);
   c[tid] = a[tid] + b[tid];
}
Language for VerCors: opencl





and this method shows the same example in CUDA:





Warning




The following example verifies only on the latest VerCors development version, not on the version currently used by the online verifier.








#include <cuda.h>
/*@
 context blockDim.x == 32 && gridDim.x > 0;
 context blockDim.y == 1 && blockDim.z == 1;
 context gridDim.y == 1 && gridDim.z == 1;
 
 context a != NULL && \pointer_length(a)> blockDim.x*gridDim.x;
 context b != NULL && \pointer_length(b)> blockDim.x*gridDim.x;
 context c != NULL && \pointer_length(c)> blockDim.x*gridDim.x;

 context Perm({:a[\gtid]:}, read);
 context Perm({:b[\gtid]:}, read);
 context Perm({:c[\gtid]:}, write);
 ensures {:c[\gtid]:} == a[\gtid] + b[\gtid];
@*/
__global__ void CUDAAdd(int a[], int b[], int c[]) {
   int tid = blockIdx.x * blockDim.x + threadIdx.x;
   c[tid] = a[tid] + b[tid];
}


Language for VerCors: cuda









In both examples, first we should include the header files (i.g., opencl.h and cuda.h). Next we obtain thread identifiers and then each thread does the computation (lines 16-17 of the OpenCL and 19-20 of the CUDA example). As we can see obtaining the global thread identifiers are different in OpenCL and CUDA.


In the specification of the methods, we specify read permission for each thread in arrays a and b and write permission in array c as pre- and postcondition. Finally in the last postcondition we specify the result of the methods that each location in array c contains the sum of the values in the corresponding locations in arrays a and b. Note that in the specification we can use the shorthand keyword \gtid instead of get_global_id(0) and blockIdx.x * blockDim.x + threadIdx.x in the tool.




Caution


We have set the kernels to be one dimensional: line 5-6 of the OpenCL and 2-6 of the CUDA example. If the kernels would be multi-dimensional, there would be a write-write race condition on c[tid] which is not allowed. Be aware that you always set the correct dimensionality in the contract of a kernel to avoid unwanted results.







Note


Normally \gtid resolves to the global thread id of all dimensions. I.e. that would be: get_global_id(0)+get_global_id(1)*get_global_size(0)+get_global_id(2)*get_global_id(0)*get_global_id(1) for OpenCL and similarly for CUDA, but since we only have one dimension it is simpler.







Important


Annotations with thread and block identifiers (such as get_global_id(0), blockDim.x, threadIdx.x) should have triggers specified (See the section about quantifiers). This is because the contract is implicitly quantified over the number of threads and number of thread blocks. Thus, a line like context Perm({:a[\gtid]:}, read); actually gets translated towards the following for the one dimensional case:




/*@ context (∀ int bid, int tid; 
     0 <= bid && bid < get_num_groups(0) &&
     0 <= tid && tid < get_local_size(0);
      Perm({:a[tid+bid*get_local_size(0)]:}, read));*/





Important


This is true for the contract of a kernel, but also the contract of a barrier, as we will see in the next section.




OpenCL/CUDA with Barrier


In GPU programming, when there is only one thread block, there is a mechanism to synchronize threads. This example shows an OpenCL program that uses barrier to synchronize threads:





Warning




The following example verifies only on the latest VerCors development version, not on the version currently used by the online verifier.








#include <opencl.h>
 
/*@
  context_everywhere get_work_dim() == 1;
  context_everywhere get_local_size(0) == n && get_num_groups(0) == 1;
  context_everywhere a != NULL && \pointer_length(a) >= n;

  requires Perm({:a[\ltid]:}, 1\2);
  requires \ltid != n-1 ==> Perm({:a[\ltid+1]:}, 1\2);
  requires \ltid == n-1 ==> Perm({:a[0]:}, 1\2);
  ensures Perm({:a[\ltid]:}, write);
  ensures \ltid != n-1 ==> {:a[\ltid]:} == \old(a[\ltid+1]);
  ensures \ltid == n-1 ==> {:a[\ltid]:} == \old(a[0]); @*/
__kernel void openCLLeftRotation(global int a[], int n) {
  int tid = get_local_id(0);
  int temp;
  if(tid != n-1) {
    temp = a[tid+1];
  } else {
    temp = a[0];
  }

  /*@
    requires \ltid != n-1 ==> Perm({:a[\ltid+1]:}, 1\2);
    requires \ltid == n-1 ==> Perm({:a[0]:}, 1\2);
    ensures Perm({:a[\ltid]:}, 1\2); @*/
  barrier(CLK_GLOBAL_MEM_FENCE);

  a[tid] = temp;
}


Language for VerCors: opencl









And this is the CUDA version of the example:





Warning




The following example verifies only on the latest VerCors development version, not on the version currently used by the online verifier.








#include <cuda.h>

/*@
  context blockDim.x == n && gridDim.x == 1;
  context blockDim.y == 1 && gridDim.y == 1;
  context blockDim.z == 1 && gridDim.z == 1;
  context_everywhere a != NULL && \pointer_length(a) >= n;

  requires Perm({:a[\ltid]:}, 1\2);
  requires \ltid != n-1 ==> Perm({:a[\ltid+1]:}, 1\2);
  requires \ltid == n-1 ==> Perm({:a[0]:}, 1\2);
  ensures Perm({:a[\ltid]:}, write);
  ensures \ltid != n-1 ==> {:a[\ltid]:} == \old(a[\ltid+1]);
  ensures \ltid == n-1 ==> {:a[\ltid]:} == \old(a[0]); @*/
__global__ void CUDALeftRotation(int a[], int n) {
  int tid = threadIdx.x;
  int temp;
  if(tid != n-1) {
    temp = a[tid+1];
  } else {
    temp = a[0];
  }

  /*@
    requires \ltid != n-1 ==> Perm({:a[\ltid+1]:}, 1\2);
    requires \ltid == n-1 ==> Perm({:a[0]:}, 1\2);
    ensures Perm({:a[\ltid]:}, 1\2); @*/
  __syncthreads();

  a[tid] = temp;
}


Language for VerCors: cuda









The above examples illustrate GPU programs that rotates the elements of an array to the left. Each thread (tid) stores its right neighbour in a temporary location (i.e., temp), except thread _size_-1 which stores the first element in the array. Then each thread synchronizes in a barrier. After that, each thread writes the value read into its own location at index tid in the array (line 28).


The precondition of the barrier follows from the precondition of the function and the computations before the barrier. If the precondition of the barrier holds, the postcondition can be assumed after the barrier. Then, the postcondition of the method can follow from the postcondition of the barrier. Note that in the specification we can use the shorthand keyword \ltid instead of _get_local_id(0)_ and _threadIdx.x_ in the tool.


Shared memory


Both in OpenCL and CUDA we support shared memory (__shared__ in CUDA and local in OpenCL). Static shared memory is declared with a compile-time known size (For example __shared__ int s[32] in CUDA and local int s[32] in OpenCL), thus the size does not need to be explicitly specified. For dynamic shared memory, you can use \shared_mem_size(s) to constraint this. See the following blur example where this is used.





Warning




The following example verifies only on the latest VerCors development version, not on the version currently used by the online verifier.








#include <cuda.h>

/*@
  context blockDim.x == 32 && blockDim.y == 1 && blockDim.z == 1;
  context gridDim.x > 0 && gridDim.y == 1 && gridDim.z == 1;
  context in != NULL && out != NULL;
  context \pointer_length(in) == n;
  context \pointer_length(out) == n-2;
  context blockDim.x * gridDim.x >= n;
  context (\forall* int i; 0<=i && i<n; Perm({:in[i]:}, write \ (blockDim.x * gridDim.x)));

  context \gtid<n-2 ==> Perm({:out[\gtid]:}, write);

  context \shared_mem_size(s) == blockDim.x+2;
  requires Perm({:s[\ltid]:}, write);
  requires threadIdx.x < 2 ==> Perm({:s[\ltid + blockDim.x]:}, write);

  ensures \gtid<n-2 ==>{:out[\gtid]:} == (in[\gtid] + in[\gtid+1] + in[\gtid+2])/3;
  
@*/
__global__ void blur_x(/*@unique<1>*/ int* in, /*@unique<2>*/ int* out, int n) {
  extern __shared__ /*@unique<3>*/ int s[];
  int tid = blockIdx.x * blockDim.x + threadIdx.x;
  if(tid < n) {
    s[threadIdx.x] = in[tid];
  }
  if(threadIdx.x < 2 && tid+blockDim.x < n){
    s[blockDim.x+threadIdx.x] = in[tid+blockDim.x];
  }

  /*@
    context (\forall* int i; 0<=i && i<n; Perm({:in[i]:}, write \ (blockDim.x * gridDim.x)));
    context blockIdx.x * blockDim.x + threadIdx.x<n-2 ==> Perm({:out[blockIdx.x * blockDim.x + threadIdx.x]:}, write);

    requires Perm({:s[threadIdx.x]:}, write);
    requires threadIdx.x < 2 ==> Perm({:s[threadIdx.x + blockDim.x]:}, write);

    requires blockIdx.x * blockDim.x + threadIdx.x < n
      ==> {:s[threadIdx.x]:} == in[blockIdx.x * blockDim.x + threadIdx.x];
    requires threadIdx.x < 2 && blockIdx.x * blockDim.x + threadIdx.x+blockDim.x < n
      ==> {:s[threadIdx.x+blockDim.x]:} == in[blockIdx.x * blockDim.x + threadIdx.x+blockDim.x];


    ensures (\forall* int i; 0 <= i && i < blockDim.x+2; Perm({:s[i]:}, write \ (blockDim.x+2)));

    ensures
      (\forall int i; 0 <= i && i < blockDim.x+2 && blockIdx.x*blockDim.x + i <n
        ==> {:s[i]:} == in[blockIdx.x * blockDim.x+i]);
  @*/
  __syncthreads();

  if(tid < n-2) {
    out[tid] = (s[threadIdx.x] + s[threadIdx.x+1] + s[threadIdx.x+2])/3;
  }
}


Language for VerCors: cuda











Note


We have used the unique type modifiers to speed up verification, which are explained in more detail in the section Unique Types.




Extract GPU Body


It is possible to extract the body of a GPU kernel with the annotation extract_body, which can speed-up verification. The following more complex GPU kernel uses this. The kernel swaps the contents of two arrays. Internally, this means the verification is modelled differently. Normally a GPU kernel is modelled has having two implicit nested parallel blocks around its code: one for the threads and one for the threads blocks. With the extract_body the code is verified in isolation in its own method, and the nested parallel blocks call this method in their body. This uses the same mechanics as the extract keyword, see the section Frames & Extract.





Warning




The following example verifies only on the latest VerCors development version, not on the version currently used by the online verifier.








#include "opencl.h"
// =================================================================================================
// This file adapated from the CLBlast project. Author(s):
//   Cedric Nugteren <www.cedricnugteren.nl>
//   Verification support: Lars van den Haak
//
// This file contains kernels to perform a swap of two vectors.

/*@
  requires a > 0 && n > 0 && x >= 0 && x < n;
  ensures 0 <= x*a && x*a <= (n-1)*a;
  ensures 0 <= x*a && x*a < n*a;
  ensures x*a / a == x;
  ensures \result;
pure bool lemma1d(int x, int n, int a);

  requires a > 0 && n > 0 && x >= 0 && x < n;
  ensures lemma1d(x, n, a);
  ensures b <= \result && \result <= b + (n-1)*a
                         && \result < b + n*a;
  ensures (\result-b) / a == x;
pure int acc1d(int x, int b, int n, int a) = (x*a + b);

  // See lean: Int.tmod_eq_emod_of_nonneg and Int.add_emod_right 
  requires a >= 0;
  requires b > 0;
  ensures (a + b) % b == a % b;
  ensures \result;
  decreases;
pure bool lemma_mod(int a, int b);

 requires b != 0;
inline pure int ceil_div(int a, int b) = (a + b - 1) / b;
*/

/*@ extract_body */
/*@
  context get_local_size(0) == 32 && get_local_size(1) == 1 && get_local_size(2) == 1;
  // Making this num of groups concrete (==10) makes verification a lot faster.
  // In general this can be any get_num_groups(0)>=0, but it takes longer.
  // run with '--prover-config:smt.arith.solver=6' if using nonconcrete num of groups.
  context get_num_groups(0) == 10 && get_num_groups(1) == 1 && get_num_groups(2) == 1;
  context n >= 1;
  context x_inc >= 1 && x_offset >= 0 && xgm != NULL && \pointer_length(xgm) >= n*x_inc+x_offset;
  context y_inc >= 1 && y_offset >= 0 && ygm != NULL && \pointer_length(ygm) >= n*y_inc+y_offset;
  context (\forall* int i; 0 <= i && i < ceil_div(n, get_global_size(0))
    && \gtid + i*get_global_size(0) < n;
      Perm({:xgm[acc1d(\gtid + i*get_global_size(0), x_offset, n, x_inc)]:}, write));
  context (\forall* int i; 0 <= i && i < ceil_div(n, get_global_size(0))
    && \gtid + i*get_global_size(0) < n;
      Perm({:ygm[acc1d(\gtid + i*get_global_size(0), y_offset, n, y_inc)]:}, write));
  ensures (\forall int i; 0 <= i && i < ceil_div(n, get_global_size(0)) && \gtid + i*get_global_size(0) < n;
        {:xgm[acc1d(\gtid + i*get_global_size(0), x_offset, n, x_inc)]:} ==
        \old(ygm[acc1d(\gtid + i*get_global_size(0), y_offset, n, y_inc)]));
  ensures (\forall int i; 0 <= i && i < ceil_div(n, get_global_size(0)) && \gtid + i*get_global_size(0) < n;
        \old(xgm[acc1d(\gtid + i*get_global_size(0), x_offset, n, x_inc)]) ==
        {:ygm[acc1d(\gtid + i*get_global_size(0), y_offset, n, y_inc)]:});
@*/
// Full version of the kernel with offsets and strided accesses
__kernel void Xswap(const int n,
           /*@unique<1>*/ __global float* xgm, const int x_offset, const int x_inc,
           /*@unique<2>*/ __global float* ygm, const int y_offset, const int y_inc) {
  /*@ loop_invariant \gtid <= id && id < n + get_global_size(0);
    loop_invariant id % get_global_size(0) == \gtid;
    loop_invariant (\forall* int i; 0 <= i && i < ceil_div(n, get_global_size(0)) 
      && \gtid + i*get_global_size(0) < n;
        Perm({:xgm[acc1d(\gtid + i*get_global_size(0), x_offset, n, x_inc)]:}, write));
    loop_invariant (\forall* int i; 0 <= i && i < ceil_div(n, get_global_size(0)) 
      && \gtid + i*get_global_size(0) < n;
        Perm({:ygm[acc1d(\gtid + i*get_global_size(0), y_offset, n, y_inc)]:}, write));
    loop_invariant (\forall int i; id/get_global_size(0) <= i && i < ceil_div(n, get_global_size(0)) 
      && \gtid + i*get_global_size(0) < n;
        {:xgm[acc1d(\gtid + i*get_global_size(0), x_offset, n, x_inc)]:} ==
       \old(xgm[acc1d(\gtid + i*get_global_size(0), x_offset, n, x_inc)]));
    loop_invariant (\forall int i; id/get_global_size(0) <= i && i < ceil_div(n, get_global_size(0)) 
      && \gtid + i*get_global_size(0) < n;
        {:ygm[acc1d(\gtid + i*get_global_size(0), y_offset, n, y_inc)]:} ==
       \old(ygm[acc1d(\gtid + i*get_global_size(0), y_offset, n, y_inc)]));
    loop_invariant (\forall int i; 0 <= i && i < id/get_global_size(0)
      && \gtid + i*get_global_size(0) < n;
        {:xgm[acc1d(\gtid + i*get_global_size(0), x_offset, n, x_inc)]:} == 
        \old(ygm[acc1d(\gtid + i*get_global_size(0), y_offset, n, y_inc)]));
    loop_invariant (\forall int i; 0 <= i && i < id/get_global_size(0)
      && \gtid + i*get_global_size(0) < n;
        {:ygm[acc1d(\gtid + i*get_global_size(0), y_offset, n, y_inc)]:} == 
        \old(xgm[acc1d(\gtid + i*get_global_size(0), x_offset, n, x_inc)]));
  @*/
  // Loops over the work that needs to be done (allows for an arbitrary number of threads)
  for (int id = get_global_id(0); id<n; id += get_global_size(0)) {
    int idx = id*x_inc + x_offset;
    //@ assert acc1d(id, x_offset, n, x_inc) == idx;
    int idy = id*y_inc + y_offset;
    //@ assert acc1d(id, y_offset, n, y_inc) == idy;
    float temp = xgm[idx];
    xgm[idx] = ygm[idy];
    ygm[idy] = temp;
  }
}
